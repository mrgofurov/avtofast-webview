# AVTOFAST --- WebView Product & UI/UX Master Prompt

## Role

You are a Senior Product Designer, UX Researcher, Design System
Architect and Frontend UI Expert.

Design the complete production-ready **WebView application** for
**Avtofast**, an AI-powered Uzbekistan driving theory learning platform.

This is **not** a dashboard. It is a **learning-first** product whose
only goal is helping users pass the official driving exam faster through
adaptive AI learning.

------------------------------------------------------------------------

## Platform

The application runs as a responsive PWA/WebView.

-   Domain: `app.avtofast.uz`
-   Telegram WebApp
-   Mobile browser
-   Android/iOS WebView
-   Touch-first experience
-   Responsive from 360px width

Design mobile-first.

------------------------------------------------------------------------

# Product Philosophy

> **Yodlash emas. Tushunish.**

Every screen must answer one question only.

-   Home → What should I learn now?
-   Topic → Learn this rule.
-   Question → Think and answer.
-   Analysis → Understand the mistake.
-   AI → Ask anything.

Never overwhelm users with statistics.

# UX Rules

1.  Every screen has one primary CTA.
2.  Maximum three hierarchy levels.
3.  Large touch targets (48px).
4.  One-hand usability.
5.  No unnecessary charts.
6.  No decorative illustrations.
7.  Fast loading skeletons.
8.  Premium whitespace.
9.  Accessibility AA contrast.
10. Feel like Duolingo × Headway × Linear.
